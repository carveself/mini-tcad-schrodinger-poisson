# 验证记录与各指标的含义

环境：Python 3.12、NumPy 2.3.5、SciPy 1.18.1、Matplotlib 3.11.2。

```bash
python run_all.py
python -m unittest discover -s tests -v
```

默认实验与 16 项测试已实际运行。默认硅厚 10 nm、每侧介质 2 nm、300 K、固定受主 1e16 cm⁻³、Ec0=0.35 eV、EF=0、栅参考偏移零；0.05 nm 均匀网格，每个能谷阶梯 32 态。栅压扫描 0.1-1.0 V，共 37 点，两种统计支路。

## 16 项测试

方阱能级及二阶误差；三角阱 Airy 低态；波函数归一化/正交/边界；积分电荷与子带占据；能谷/自旋占据与能量积分；经典费米积分及导数的独立自适应积分；电荷平衡和真泊松残差；双栅对称/密度非负；量子质心/电荷趋势；冻结势阱的独立 FEM；联合非线性求根；混合/偏压路径；态数/网格；栅电容/微分步长；截断/不收敛拒绝；无效输入。

## 反馈、路径与真残差

默认扫描最大真电荷泊松电压修正小于 4e-11 V，最大相对高斯电荷平衡误差约 3.01e-8。较弱电荷时相对误差容易被小分母放大；这不是整个物理模型误差。

混合比例 0.35/0.6/0.9 从相同默认初值求 0.8 V，分别约 77/40/21 次外迭代，最后最大电势差小于 3e-12 V。联合求根在 0.25 nm 网格从经典解起步，约 57 次函数评估，与预测器算法电势差约 3e-12 V。两种算法共享离散系统，只验证非线性求解的一致性。

单次量子后处理面密度约 2.64043e12 cm⁻²，自洽值为 7.62753e12 cm⁻²，相差约 -65.38%。不能把一次后处理当成量子自洽器件模型。

## 截断诊断

冻结 0.8 V 自洽势阱后，相对 32 态参考，4 态面电荷低约 0.9083%，8 态低约 1.24e-6（相对值）；16/48 态差异已接近数值舍入。末尾三态占据很小不构成未保留态总和的严格界，因此还提供实际增态比较。

## 文件索引

- `figures/bias_sweep.csv`：量子/经典的面密度、最近界面距离、电容、残差、能谷信息；经典不适用的子带列为空。
- `figures/density_profiles.csv`、`subbands.csv`：剖面与态能量、面占据。
- `figures/quantum_state.npz`：0.8 V 的 z（m）、电势（V）、密度（m⁻³）、两组能级（eV）和波函数（m⁻¹/²）。
- `figures/thickness_criterion.csv`、`oxide_criterion.csv`：同面电荷的栅压比较。
- `figures/mesh_convergence.csv`、`exact_spectra.csv`：网格和解析/独立谱对照。
- `figures/state_truncation.csv`、`capacitance_steps.csv`、`mixing_check.csv`：态数、微分、混合检查。
- `figures/iteration_traces.json`：逐步真泊松修正与未混合更新。
- `figures/summary.json`、`validation.json`：参数、主要结果、验证指标与范围说明。

所有数据来自理想模型计算，无随机数据或实测数据。更改参数后应保留自己的记录；静态报告中的默认数字不会自动变成新参数的结论。不同库版本/平台可能改变末位与 PNG 编码，按合理容差比较物理量，不以图像哈希判断科学一致性。
