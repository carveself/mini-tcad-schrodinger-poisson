# 量子薄硅模型：方程、单位和数值方法

## 几何与物理范围

z 从 0 到 tSi，硅厚 3-20 nm，两侧均为无体电荷的理想介质。上下栅短接，电子在面内平移不变，与侧向电荷库热平衡。EF=0，Ec(z)=Ec0-psi(z)，能量使用 eV，psi 使用 V。

默认 Ec0=0.35 eV 是给定对齐参数，不从体区电中性求得。固定受主不要求零栅压下硅体区电中性，电荷由两栅补偿；本模型是薄膜电子支路，不是厚体 p 型 MOS 的完整空穴模型。`gate_offset_V` 是电压参考偏移，不应称作已提取的实验平带电压。没有源漏电流。

电子采用无限高介质势垒，包络波函数在两个硅端面为零。Poisson 的电势边界仍由两侧氧化层电容给出，不能把波函数 Dirichlet 边界误当成电势必须为零。

## 两组能谷与占据

采用常数纵/横质量 ml=0.916m0、mt=0.190m0。未考虑应变与谷分裂。

| 组 | 能谷数 gv，不含自旋 | 限域质量 mz/m0 | 面内 DOS 质量 md/m0 |
| --- | ---: | ---: | ---: |
| Δ2 | 2 | 0.916 | 0.190 |
| Δ4 | 4 | 0.190 | sqrt(0.916×0.190) |

在每组求：

```math
\left[-\frac{\hbar^2}{2m_z}\frac{d^2}{dz^2}+q(E_{c0}-\psi)\right]F_i=qE_iF_i,
\qquad F_i(0)=F_i(t_{Si})=0.
```

单位换算中 qEi 是 J；程序直接把动能系数除以 q，构造以 eV 为单位的三对角矩阵。波函数满足积分 |Fi|² dz=1，单位 m⁻¹/²。均匀网格内点中心差分，`eigh_tridiagonal` 只求所需最低态，再按网格步长归一化。

含自旋 2 的子带面占据为：

```math
N_i=\frac{g_v m_d k_BT}{\pi\hbar^2}
\ln\left[1+\exp\left(\frac{E_F-E_i}{V_T}\right)\right],
\qquad V_T=k_BT/q.
```

这里 EF、Ei 用 eV，因此指数分母是 VT 的数值；前因子中的 kBT 仍用 J。自旋已包含在系数，不能再乘 2。面密度 Ni 为 m⁻²，体密度 `n(z)=sum Ni*|Fi(z)|²` 为 m⁻³。`logaddexp` 避免指数溢出。

相同参考下的经典局域模型使用三维 Fermi–Dirac 积分：

```math
n_{cl}=\sum_v N_{c,v}F_{1/2}[(\psi-E_{c0})/V_T],
\quad N_{c,v}=2g_v\left(\frac{m_0 k_BT}{2\pi\hbar^2}\right)^{3/2}
m_d\sqrt{m_z}.
```

最后式中的 md、mz 为以 m0 归一化的质量。归一化的 F1/2 为 `(2/sqrt(pi))*积分 sqrt(t)/(1+exp(t-eta)) dt`。变换 t=x² 后，用 384 点 Gauss–Legendre 积分，截止在最高 eta 以上 50kT；导数对同一被积函数求出。测试用自适应积分核查 eta=-20、0、10、30、80。高 eta 时占据导数较尖，早期较低积分点数不能满足同样精度，这个问题已通过提高分辨率解决。

## 保守泊松与栅边界

```math
-\varepsilon_{Si}\psi''=-q(N_A+n),\qquad C_{ox}=\varepsilon_{ox}/t_{ox}.
```

左端的节点控制体方程为：

```math
\frac{\varepsilon_{Si}}h(\psi_0-\psi_1)
+C_{ox}(\psi_0-V_g+V_{off})
=-q(N_A+n_0)h/2.
```

右端对称，内节点使用完整控制区间 h。经典模型的端面载流子电荷也进入半单元；量子模型端面 n=0。如此同一个梯形积分权重既用于归一化/面电荷，也用于端电荷平衡。

两栅总电荷为 `Cox*(Vg-Voff-psi(0))+Cox*(Vg-Voff-psi(tSi))`，与硅体电荷之和应为零。代码将方程除以 eps/h，三对角线性算子记作 A；残差 r 经 A 的逆作用后具有 V 的单位，作为真电荷的电势修正指标。

## 自洽循环及假收敛防护

1. 给定 psi，分别求两个能谷阶梯、费米占据和真实量子密度 nq。
2. 内层预测密度取 `n_pred(z)=nq(z)*exp((psi_trial-psi_old)/VT)`，用阻尼牛顿法解预测泊松。
3. 以混合系数更新电势，重新求薛定谔与真实密度。
4. 未混合的预测器更新低于 2e-11 V，且真实残差经 A⁻¹ 得到的最大修正低于 4e-11 V，才接受。

预测器的局域玻尔兹曼响应只是预条件，最终电荷始终由真实子带费米统计重算；不会把局域预测器当成量子物理模型。内层步长与线搜索处理较差初值，偏压扫描复用前一偏压解。超出迭代上限、线搜索失败或保留态尾部占据过大都抛出错误，不输出伪收敛结果。

末尾三态的占据比例仅用于保守诊断。4/8/16/32/48 态的比较在冻结电势下进行；未解多个不充分截断模型并把它们标作完整收敛器件。

## 独立参考的含义

谱参考是 P1 线性有限元的广义特征值问题 Kf=EMf：动能用形函数梯度装配，质量矩阵一致积分，给定势按分段线性插值并用两点 Gauss 精确积分单元内三次乘积。它不复用三对角差分哈密顿量。两套都采用相同有效质量和无限边界。

该参考只作用于冻结的已收敛电势，因此验证的是谱的离散，不是另一套独立完整自洽模型。比较误差包含势插值/离散的差异。

`coupled_root` 在 0.25 nm 网格用经典解起步，对真实量子密度残差作联合数值求根。它与预测器迭代算法不同，但共享同一差分方程；只能检查迭代算法的一致性。不能将两者一致理解为对真实器件的独立物理验证。

已知解包括无限深方阱 `En=hbar²*pi²*n²/(2mL²)` 和半无限线性势 `En=|a_n|*(hbar²*F²/(2m))^(1/3)`。后式若用 SI，F 是 J/m 的势能梯度，En 为 J；程序以 eV·nm² 的动能系数配合 eV/nm 斜率求 eV。Airy 零点由 SciPy 给出；数值用 20 nm 远壁近似半无限域，仅检查前三个低态。

## 面电荷、质心与电容

对称双栅的全膜平均 z 恒为 tSi/2；改用 `d(z)=min(z,tSi-z)`，报告积分 n*d 除以积分 n。它量化到最近界面的距离，不应叫作偏向某一栅的全膜质心。

以 Ns=1e12 cm⁻² 求栅压，称“面电荷判据电压”。该判据不自动等于某种传统阈值定义。对称双栅下每侧栅电荷为 `q*(Ns+NA*tSi)/2`。同 Ns 时量子与经典总电荷相同，因而在 `Vg=psi_surface+Qg_single/Cox+Voff` 中氧化层项相消，量子电压偏移等于硅表面电势差。在该模型中改变 tox 而保持其他条件和 Ns，两个判据栅压一起移动、差值几乎不变；这与固定 Vg 的实验是不同的问题。

准静态栅电容用对两个邻近栅压分别重新自洽后的总栅电荷中心差分，基准指标步长为 1 mV，再用 2/0.5 mV 复核。主扫描图由 25 mV 间隔的梯度得到，省去端点；图示粗差分与单点高分辨率结果用途不同。

冻结谱的量子电容为 `q*dNs/dEF(eV)`；这是电荷库化学势变化的响应，不是测量栅端电容。分布电荷和静电反馈使简单的两个集中电容串联式不必精确成立。所有电容为 F/m²，实际面积为 A 时乘 A 才是 F。

## 未包含的物理

没有空穴、非完全电离、交换关联、有限介质势垒与质量跳变、隧穿、原子能带、应变/谷分裂、界面陷阱、粗糙散射、自热或输运。EF 与导带对齐是给定边界条件；改变它们会改变数值结论。3 nm 和高场结果主要说明这个理想模型的趋势，不能作为真实工艺精度承诺。
