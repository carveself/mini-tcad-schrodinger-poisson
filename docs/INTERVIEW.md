# 复试项目讲述与追问

材料用于真实复现之后练习专业表达，不代表院校认可或录取加分。参考实现、工具辅助和自己重写的部分应如实区分。

## 三分钟技术练习

**约 30 秒，问题。** 我复现了一个薄硅双栅 MOS 的薛定谔–泊松自洽模型，研究量子限域怎样改变电子分布和栅电容。垂直方向量子化，面内电子仍有连续动能；所以需要从子带态密度积分求面占据。

**约 45 秒，方法。** 两组 (001) 硅能谷使用不同的限域质量、面内 DOS 质量和 2/4 能谷权重。先求能级与波函数，再按费米统计计算电子密度反馈泊松。氧化层形成电势 Robin 条件，波函数则采用无限壁零值；这两种边界不能混淆。

**约 45 秒，验证。** 我检查方阱、Airy 阱、波函数归一化、独立 FEM 谱、网格、态数和电容步长。FEM 是冻结势阱验证；联合求根是同一离散系统的另一算法。小残差和电荷守恒不能独自证明所有物理假设都准确。

**约 40 秒，一个结果。** 0.8 V 下量子电子离界面更远，面密度和栅电容低于同统计的经典模型。在 1e12 cm⁻² 的同电荷判据下，栅压高约 21.4 mV。若只在经典势阱做一次量子后处理，会少算约 65% 面电荷，说明反馈很重要。

**约 20 秒，贡献与限制。** 加入自己实际完成的修改、失败与验证证据。模型不解空穴、有限势垒、交换关联或输运；我的结论只在所选模型和参数内成立。

## 英文简介

I reproduced a self-consistent Schrodinger-Poisson model for a thin (001) silicon double-gate MOS structure. The model resolves two valley ladders, integrates the in-plane Fermi-Dirac occupation, and feeds the electron charge back into Poisson's equation. I compare it with a classical model using the same statistics and material parameters. Validation includes exact spectra, an independent finite-element eigenproblem, mesh refinement and an alternate nonlinear solver. The main limitations are infinite barriers, fixed acceptors, an electron-only equilibrium branch and no exchange-correlation or transport.

## 追问与回答线索

| 问题 | 回答方向 |
| --- | --- |
| 为什么只有一个空间方向求波函数？ | 面内平移不变，垂直受限；面内动能通过二维 DOS 积分进入占据 |
| 量子化质量和 DOS 质量一样吗？ | Δ2/Δ4 的 mz 与 md 不同；前者决定限域动能，后者决定面内态数 |
| 为什么不是每个能级乘一个 f(Ei) 就结束？ | 每个子带还包含连续面内动能，需要积分，得到 log(1+exp) |
| 自旋与能谷如何计数？ | 表中 gv 只含谷，公式已含自旋 2；不能重复乘 |
| 为什么量子密度在界面为零？ | 无限势垒的模型边界，真实有限势垒可能渗透；不是对所有界面的普适结论 |
| 波函数为零，电势也应为零吗？ | 不应；电势由氧化层与栅压 Robin 条件决定 |
| 对称器件的电荷质心为什么不直接用平均 z？ | 它恒在中间，需用最近界面距离才能显示空间重排 |
| 经典对照是否用玻尔兹曼？ | 使用三维费米统计，与量子同材料和电荷库；避免混入统计近似误差 |
| 为什么一次量子后处理不够？ | 量子电荷改变屏蔽和势阱，新的势阱又改变占据 |
| 局域指数预测器是不是把量子模型偷换成经典？ | 只是泊松预条件；接受解时重算真实量子密度与残差 |
| 混合比例很小，更新就小，算收敛吗？ | 不一定；检查未混合更新与真电荷残差对应电势修正 |
| 独立 FEM 验证什么？ | 同一冻结电势下的谱离散；不是另一套完整自洽器件模型 |
| 21.4 mV 是真实阈值偏移吗？ | 明确是 1e12 cm⁻² 面电荷判据与给定对齐下的模型结果 |
| 同电荷时改变 tox，偏移为何几乎不变？ | 两模型总电荷相同，氧化层压降在差值中相消；固定 Vg 时不成立，有限势垒等更完整物理也可能改变结论 |
| 量子电容和栅电容为什么不同？ | 前者冻结谱对电荷库化学势微分，后者改变栅压并完整自洽，包含氧化层与空间分布 |
| 近机器精度的两算法一致说明什么？ | 同一离散方程求解一致，不证明缺失的物理也正确 |
| 哪部分是你自己的工作？ | 指向真实重写、排错、网格和扩展日志，说明工具与参考实现 |
