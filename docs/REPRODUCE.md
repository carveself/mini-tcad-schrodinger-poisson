# 第五阶段复现：从量子阱到量子电容

先保留参考版本，按主 README 跑通默认实验和 16 项测试，再创建自己的复现分支。每一步记录推导、修改、失败与验证，不把运行现成脚本等同于独立实现。

## 1. 先重写独立薛定谔求解器

阅读 `hamiltonian`，用 1D 无限深方阱检验前 3 个能级。动能原本是 J，为什么矩阵系数要除以 q 才能得到 eV？把质量加倍、厚度加倍，先预测能级的变化再运行。

检查波函数端点为零、积分模平方为 1，以及态间正交。不能把线性代数库返回的欧氏归一化向量直接当作物理归一化波函数。

## 2. 推导子带面占据

从面内二维抛物能带的态密度与费米分布积分，得到 `log(1+exp((EF-Ei)/VT))`。逐项写单位，标明能谷和自旋。Δ2/Δ4 的量子化质量和面内 DOS 质量不是同一个数。

需要解释：为什么不能用一个单能级的占据概率 f(Ei) 直接当成整个子带电子数？为什么不能只按 2/6、4/6 分配载流子？

## 3. 运行基准并读原始数组

```bash
python src/stages.py baseline --output reproduction/01-baseline
```

默认 0.8 V 的量子/经典面密度约 7.62753e12/9.02403e12 cm⁻²。打开 NPZ，检查两个能谷的波函数维度、单位与积分；将密度积分与各子带面占据之和比较。

对称结构的全膜平均 z 恒为 5 nm，不能用它证明量子电荷远离界面。重写最近界面距离积分，复现量子 2.41141 nm、经典 1.28425 nm。

## 4. 亲手接入泊松反馈

从节点控制体推导内节点与界面半单元方程。说明为什么波函数端点为零，而电势端点由氧化层 Robin 条件决定。

```bash
python src/stages.py feedback --output reproduction/03-feedback
```

比较经典电势上的单次量子后处理与完整自洽。默认前者仅约 2.64043e12 cm⁻²。解释电子电荷减少后势阱为何会重新调整。

动手：改变混合比例 0.35/0.6/0.9，记录迭代数和最后电势。不要只看“混合后的更新很小”，还要计算真正量子电荷下的泊松残差对应电压修正。

## 5. 建立多层验证

```bash
python src/stages.py verify --output reproduction/02-verification
```

先复现方阱二阶、三角阱 Airy 能级；再比较同一电势下有限差分与独立 FEM 的谱。说明它为什么不是完整自洽模型的第二套独立解。

比较 0.1/0.05/0.025 nm 网格的面电荷、质心、基态和电容。态数实验在冻结电势下比较 4/8/16/32/48 态；把保留末态占据诊断与实际加态后的变化区分开。

动手：用太少态求完整自洽，观察程序拒绝结果的错误。再扩展态数并复核；不要为了“跑通”而直接关掉截断检查。

## 6. 重现同电荷判据偏移

```bash
python src/stages.py geometry --output reproduction/04-geometry
```

以 Ns=1e12 cm⁻² 提取栅压，默认量子 0.344363 V、经典 0.322953 V，差约 21.41 mV。这里是面电荷判据，不应直接叫作实测阈值。

先推导为什么 1/2/4 nm 介质在相同 Ns 下的量子偏移几乎相同：两栅总电荷由 Ns 和固定受主决定，相同的氧化层压降在两模型之差中相消。再对比固定 Vg 而改变 tox 的实验；控制条件不同，回答的问题也不同。

扩展：更换 Ns 判据，或者在一个硅厚下扫描温度，保持 Ec0、栅参考、质量和统计约定不变。改变温度会同时改变统计和自洽电荷，不要把所有变化都称为“零点能变化”。

## 7. 真正计算电容

写出两栅总电荷的中心差分。每一个邻近偏压都必须重新自洽；只改变费米占据、冻结电势得到的是另一种响应。对比 2/1/0.5 mV 步长。

解释为什么冻结谱量子电容约 0.414829 F/m²，而栅端准静态电容约 0.0260837 F/m²。后者包括氧化层、分布电荷和静电反馈。它不是高频电容或漏端小信号参数。
